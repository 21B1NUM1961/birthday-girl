# 💖 Найз охиндоо зориулсан Төрсөн өдрийн интерактив бэлэг (Vercel Ready)

Энэхүү төсөл нь таны найз охиндоо зориулсан 3 шатлалт, дуу хөгжим, хөдөлгөөнт дүрслэл (animation) бүхий төрсөн өдрийн сюрприз вэб хуудас юм. Vercel дээр ямар ч нэмэлт тохиргоогүй шууд үнэгүй байршуулахад (deploy хийхэд) 100% бэлэн хийгдсэн.

---

## 🌟 Төслийн бүтэц ба үйл явц

1. **1-р алхам (Нүүр хуудас):**
   - Романтик жаазтай зураг (найз охиныхоо зургийг оруулах боломжтой, анхдагчаар хөөрхөн вектор зурагтай).
   - Хамгийн нандин хүндээ зориулсан мэндчилгээ.
   - **"Үргэлжлүүлэх 💖"** гэрэлтсэн товч (Дармагц намуухан ая эгшиглэж дараагийн шатанд шилжинэ).

2. **2-р алхам (Торт ба Лаа үлээх):**
   - Дээр нь: **"Лаагаа үлээгээрэй 🎂"** гарчиг.
   - Голд нь: Бодитоор дүрэлзэн асч буй 3 лаатай, крем нь урссан үзэсгэлэнт төрсөн өдрийн торт.
   - Доор нь: **"Одоогоор лаа үлээхийг мэдэрдэг код байхгүй тул бялуу дээр дараарай 🤫✨"** заавар.
   - Бялуу дээр дарахад: Лаа үлээгдэн унтарч, утаа савсан гарч, салют (confetti) бууран дараагийн шатанд автоматаар шилжинэ.

3. **3-р алхам (Хөдөлдөг сарнай ба Баярын мэнд):**
   - **"Төрсөн өдрийн мэнд! 💖"** гэрэлтсэн баярын гарчиг.
   - **Хөдөлдөг сарнай (Animated Blooming Rose):** Салхинд найгах иш, навч болон дэлбээлэн дэлбээгээ нээж амьд мэт хөдлөх улаан сарнай.
   - Сарнай дээр дарахад дэлгэцээр зүрхнүүд цацарна.
   - Хайрын захианы тусгай хэсэг (өөрийн хүссэн сэтгэлийн үгээ бичих боломжтой).
   - "Зүрх илгээх ❤️" болон "Дахин үзэх 🔄" товчлуурууд.

4. **Нэмэлт онцлогууд:**
   - **Арын фон:** Дэлгэцээр зөөлөн хөвөн унах сарнайн дэлбээнүүд (Canvas animation).
   - **Хөгжим:** Web Audio API ашиглан интернэт тасарсан ч гацахгүй дуугардаг намуухан хөгжмийн хайрцагны ая (баруун дээд буланд Унтраах/Асаах товчтой).
   - **Утас, таблет, компьютер дээр төгс харагдана** (100% Mobile Responsive).

## 🛠️ Өөрийн болгож өөрчлөх (Customization)

### 1. Зургийг солих:
Найз охиныхоо хамгийн хөөрхөн зургийг аваад нэрийг нь `photo.jpg` болгоод `images/` фолдер дотор хуулж тавихад л хангалттай! Вэб автоматаар таны зургийг харуулна.
> Хэрэв өөр нэртэй зураг оруулах бол `index.html` файлын 48-р мөрөнд байгаа `src="images/photo.jpg"` гэснийг солиорой.

### 2. Сэтгэлийн үгээ солих:
`index.html` файлыг текст засварлагчаар (эсвэл VS Code-оор) нээгээд:
- **Нүүр хэсгийн бичиг:** 57-65-р мөр
- **Хайрын захианы хэсэг:** 206-218-р мөр
дээрх монгол бичвэрүүдийг найз охиныхоо нэр болон өөрийн үгээр өөрчилж болно.

## 🚀 Компьютер дээрээ урьдчилан үзэх (Local preview)

Хамгийн амархан арга:
- Энэ фолдер доторх `index.html` файлыг шууд хулганаараа 2 товшоод дурын вэб хөтөч (Chrome, Safari, Edge) дээрээ нээж үзнэ.

Эсвэл терминал дээр:
```bash
npx serve .
```

## ☁️ Vercel дээр байршуулах (Deploy хийх заавар)

Vercel дээр үнэгүй байршуулахад 1-хэн минут болно. Дараах 3 аргын аль нэгийг сонгоорой:

### Арга 1: Vercel вэб сайт дээр шууд байршуулах (Хамгийн хялбар)
1. [vercel.com](https://vercel.com) руу ороод бүртгүүлнэ (эсвэл GitHub аккаунтаараа нэвтэрнэ).
2. Энэ төслийн фолдероо GitHub дээр шинэ репозитор (repository) үүсгээд push хийнэ.
3. Vercel dashboard дээрээ **"Add New..." -> "Project"** дарж тухайн репозитороо сонгоно.
4. **"Deploy"** товчийг дарахад л хэдхэн секундийн дараа танд найз охиндоо илгээх `https://таны-нэр.vercel.app` холбоос бэлэн болно!

### Арга 2: Vercel CLI ашиглах (Терминалаас)
Терминал дээр төслийн фолдер дотроо дараах тушаалыг бичнэ:
```bash
npx vercel
```
- Нэвтрэх зааврыг дагана.
- Асуултуудад `Enter` дарж зөвшөөрөхөд шууд холбоос үүснэ.
